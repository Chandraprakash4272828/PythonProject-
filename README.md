# AI-Powered Chatbot 🤖

An AI-powered FAQ chatbot built using Natural Language Processing (NLP), FastAPI, and SQLite.

## 🚀 Features
- NLP-based intent matching using TF-IDF
- FastAPI backend with REST endpoints
- SQLite database for chat logs
- Interactive Swagger UI
- Modular and deployable architecture

## 🛠️ Tech Stack
- Python
- FastAPI
- NLTK
- Scikit-learn
- SQLite
